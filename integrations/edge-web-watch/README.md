# Edge 网页互动扩展（大肥鱼桌宠）

桌宠的「网页互动」功能由两部分组成：桌宠里的**本地接收端**（默认关闭）和这个
**Edge 扩展**（负责采集当前页面）。扩展只把事件发往本机 `127.0.0.1`，由你电脑上的
桌宠接收；除你自己配置的模型服务商外，不发往任何第三方。

## 一、在桌宠里开启

1. 右键桌宠 → 设置（或托盘菜单 → 设置）→ **网页互动**；
2. 打开「启用网页互动」开关，**保存**；
3. 记下这一页显示的 **端口**（默认 `8765`）和 **访问令牌**（32 位十六进制，桌宠首次
   开启时自动生成，存在 `%APPDATA%\dsh-pet-standalone-webm-chat\web_watch_token.txt`）。

> 建议先点一次「dry-run 验证模式」保存，再去浏览几个网页——命中只写日志、不调用模型、
> 不花额度；确认日志里能看到命中，再关掉 dry-run 正式使用。

## 二、在 Edge 里加载扩展

1. 地址栏输入 `edge://extensions` 回车；
2. 打开左下角（或右上角）的 **开发人员模式**；
3. 点 **加载解压缩的扩展**，选择本目录：
   - 安装版：`<桌宠安装目录>\_internal\integrations\edge-web-watch`
   - 源码版：`<仓库>\integrations\edge-web-watch`
4. 扩展列表里点「详细信息」→ **扩展选项**，填入上一步的**端口**与**令牌**，点「测试连接」，
   看到「连接正常，桌宠：<名字>」即通；
5. 保存。之后正常浏览网页即可。

## 三、它什么时候会说话

| 触发 | 说明 |
| --- | --- |
| 换页停留 | 同一页停留超过「停留门限」（默认 8 秒）→ 评论一句 |
| 正文增量 | 长文/文档页新加载出的正文超过阈值（默认 400 字）→ 再补一句 |
| 划词 | 你选中一段文字 → 优先针对这段评论 |
| 视频进度 | 视频播放超过「首句时刻」（默认 20 秒）→ 评论一次 |
| 发呆建议 | 在代码/文档/论文/新闻/问答页停留且你离开键鼠一段时间 → 给一条**建议** |

两条硬保护：**全局冷却**（默认 2 分钟内不会连着说）与**每日上限**（默认 60 次），
外加连续失败自动熔断当天——都由桌宠侧记账，改配置即可调整。

## 四、隐私边界

- 只读页面**可见文本**（标题/小标题/正文摘要），**没有**读取任何输入框值的代码路径；
- 页面含密码框（登录、支付、改密）时整体停发；
- URL 的查询串（`?a=1`）与锚点在桌宠侧**统一丢弃**（搜索词、token、追踪参数不进模型）；
- 角色记忆里不落窗口标题；
- 排除名单：扩展的「这些网站不发送」逐行写域名；桌宠侧还有一份黑名单（默认对
  银行/邮箱类域名更安全）；
- 关闭桌宠的「启用网页互动」开关，接收端会立刻释放端口，任何东西都送不进来。

## 五、排查

| 现象 | 处理 |
| --- | --- |
| 扩展图标出现红色 `!` | 发送失败：打开扩展选项点「测试连接」看具体原因 |
| 「令牌不匹配」 | 桌宠重启/重装后令牌可能变了：回到桌宠设置页重新复制令牌 |
| 「连不上本机桌宠」 | 桌宠没在运行，或「网页互动」没保存开启，或端口不一致 |
| 完全没反应 | 先开 dry-run 看桌宠日志（`%APPDATA%\dsh-pet-standalone-webm-chat\pet-<pid>.log`）里有没有 `web_watch [dry-run]` 命中 |
| 不想要评论只想建议 | 桌宠设置页关掉「评论」类开关，保留「建议」 |
